Partitions musicales VocalGuard (jingles + fonds sous la voix)

Source code : backend/voice/audio_utils.py
  _STINGER_SCORES      — jingles d'intro (sting_*, sfr_*)
  _VOICE_BED_SCORES    — fonds composes sous l'annonce (bed_*)

Format note : (frequence Hz, duree relative en secondes)

  Notes     : 440.00, 554.37, 659.25, 880.00, 659.25
  Noms      : La4, Do#5, Mi5, La5, Mi5
  Timbre    : marimba

=== FONDS SOUS LA VOIX (bed_*) ===
Joues pendant le message TTS, volume reglage greeting_intro_voice_bed_db (defaut -24 dB).

bed_marimba_warm — Marimba doux, La majeur
  Pad racine : La3 (220 Hz)
  Arpege    : La3, Do#4, Mi4, Do#4 (boucle)
  Timbre    : marimba + nappe

bed_corporate_pad — Pad corporate, Do majeur
  Pad racine : Do4 (261.63 Hz)
  Arpege    : Do4, Mi4, Sol4
  Timbre    : piano + nappe

bed_calm_wave — Vague calme, Sol majeur
  Pad racine : Sol3 (196 Hz)
  Arpege    : Si3, Sol3, Re4, Si3
  Timbre    : acoustic + nappe

bed_amber_resolve — Ambre, Si majeur
  Pad racine : Si3 (246.94 Hz)
  Arpege    : Si3, Re#4, Fa#4, Re#4
  Timbre    : marimba + nappe
